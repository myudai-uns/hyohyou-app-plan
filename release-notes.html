概要

  • 第2版（Windows 専用）から、Raspberry Pi（Linux）にも対応
  • Windows / Pi の両環境で同一機能を提供
  • Pi 版は製造ライン常時表示用途に最適化
  • 同一ソースコードから exe 版と py 版を生成
  • ソースコード行数：2,160 行 → 2,430 行

新機能

  • Raspberry Pi（Linux）対応：OS自動判定により Windows / Pi で同一の main_v3.py が動作
  • Pi 版セットアップ機能を内蔵：python3 main_v3.py --setup で apt install / pip install / 自動起動設定を一括実行
  • 自動起動設定機能：--install-autostart で ~/.config/autostart/hinpyo.desktop を自動生成
  • 常時表示モード：Pi 版は無操作でも電源OFFまで起動継続
  • フォント自動切替：Windows = Segoe UI、Pi = Noto Sans CJK JP を OS別に自動選択
  • フルスクリーン方式の OS別実装：Windows = zoomed、Linux = -fullscreen を自動切替
  • 相対パスでの PDF 指定対応：実行ファイル基準でパス解決
  • 動作確認用サンプルPDF 20件を納品物に同梱
  • 初期設定済み config.json 同梱：起動直後から 20スロット表示

その他改善

  • PDF表示位置を表示領域中央に最適化
  • Linux（Pi）でのCtrl+マウスホイールズーム対応
  • Shift+マウスホイールズームを追加
  • タッチパネル操作向けのボタン拡大

バグ修正

  • Pi 版で意図せず自動終了する重大バグを修正（操作のたびにタイマーが登録されていた）
  • フルスクリーン切替後にボタン枠線が消える事象を修正（マウスを乗せると復活していた）
  • 設定画面が空表示になる問題を修正（grab_set のタイミング不良）
  • Pi 版で ImageTk のインポートに失敗する問題を修正（python3-pil.imagetk を自動インストール対象に追加）
  • 設定画面の geometry/minsize 矛盾を解消
  • フォント変数化過程の自己参照バグを除去
  • Wayland 環境でスクロールバーが極細になる問題を修正

内部変更

  • 識別子・パスを ASCII化：hinpyo_pi_v3.0 / hinpyo_exe_v3.0 / hinpyo_app.exe / hinpyo.desktop に統一
  • IconBtn クラスに rect / w / h / font_size パラメータを追加
  • サンプルPDF生成スクリプト（generate_sample_pdfs.py）を新規追加
  • spec ファイル名・出力名を統一（main_v3.spec → hinpyo_app.exe）
  • テスト用CLIフラグ（--auto-fs, --auto-load1）は本番ビルドから削除

動作環境

Windows 版（exe）

  • OS：Windows 10 / 11
  • 追加インストール不要（単体exeで完結）
  • サイズ：約 54MB

Raspberry Pi 版（py）

  • OS：Raspberry Pi OS（Bookworm 64-bit 推奨）
  • Python：3.8 以降
  • 依存ライブラリ：PyMuPDF、Pillow、python3-tk、python3-pil.imagetk
  • フォント：fonts-noto-cjk、fonts-noto-color-emoji
  • サイズ：約 75KB（依存除く）
