★ ハイライト

第3版では Raspberry Pi（Linux）対応を実現し、Windows / Pi 両OSで同一機能を提供します。Pi 版は「常時表示用」として自動起動・自動終了無効化に対応。ライブラリ最大20件・タッチパネル操作にも対応した、製造ラインでの常設運用に最適化されたバージョンです。

🎯
新機能
9件
NEW
Raspberry Pi (Linux) 対応
起動時に sys.platform を判定し、OS別に動作を自動切替。Windows / Pi の両環境で同一の main_v3.py が動作します。第2版は Windows 専用で、Pi では起動できなかった
NEW
Pi 版自動セットアップ機能を内蔵
python3 main_v3.py --setup で apt install (日本語フォント・GUI ライブラリ) + pip install (PyMuPDF, Pillow) + 自動起動設定を一括実行。--install-autostart で自動起動のみ設定も可。.sh / .desktop ファイルを別途配布しなくても、py ファイル1つで完結する
NEW
常時表示モード（Pi 版・自動終了無効）
Pi 版では AUTO_EXIT_ENABLED = False を自動設定し、無操作でも電源OFFまで起動し続ける。製造ラインでの常設運用に必要
NEW
フォント自動切替（OS別）
Windows = Segoe UI / Segoe UI Emoji、Pi = Noto Sans CJK JP / Noto Color Emoji を自動選択。約30箇所のフォント指定を変数化。Pi に Segoe UI が無いため、第2版は Pi で日本語が□表示になる
NEW
フルスクリーン方式の OS 別実装
Windows = state("zoomed")、Linux = attributes("-fullscreen", True) を自動選択。Tk の "zoomed" state は Windows 限定で、Linux では例外発生する
NEW
相対パスでの PDF 指定対応
設定ファイル内のPDF パスが相対パス（PDF/sample_01.pdf 等）でも、実行ファイルと同じフォルダ基準で解決される。exe を別フォルダにコピーしても PDF が見つかる
NEW
2バージョン納品体制
単一ソース main_v3.py から、Windows 用 exe 版と Pi 用 py 版を生成。納品時はそれぞれ独立フォルダ（hinpyo_exe_v3.0/ ／ hinpyo_pi_v3.0/）に配置。先方の要望「両方納品」に対応しつつ、開発側は1ソース管理で効率化
NEW
動作確認用サンプルPDF 20件を同梱
納品物に各種設計仕様書を模した品標 20件を同梱。実運用時は正式な品標 PDF と差し替え。第2版は PDF 別途用意が必要だった
NEW
事前設定済み config.json
納品物に 20スロット登録済みの設定ファイルを同梱。初回起動時から全PDFがサイドバーに表示される。初期セットアップの手間を削減

バグ修正
7件
FIX
Pi 版の意図しない自動終了を修正（重要）
_reset_idle_timer が AUTO_EXIT_ENABLED の判定をしておらず、ズーム・スクロール等の操作のたびに終了タイマーが登録されてしまっていた。Pi 版で 1分後にアプリが突然終了する現象を解消。常時表示運用を阻害する重大バグ
FIX
フルスクリーン時にボタン枠線が消える事象を修正
Wayland のフルスクリーン遷移で Canvas の描画コンテンツがクリアされ、Tk が自動再描画しない問題に対応。_redraw_canvas_widgets() をフルスクリーン切替後に2回呼び出し（150ms / 400ms）。マウスを乗せた時のみ枠線が出る現象が発生していた
FIX
設定画面が空表示になる問題を修正
grab_set() がウィンドウ表示前に呼ばれて例外発生し、後続の UI 構築が中断されていた。wait_visibility() 後に grab_set() を呼ぶよう変更。さらに Canvas サイズを update_idletasks で確定後にスクロール領域を設定。Pi 版で設定画面を開いても何も表示されなかった
FIX
ImageTk インポートエラー対応
python3-pil.imagetk パッケージを --setup 時に自動インストール対象に追加。Pi の Pillow と PIL.ImageTk の連携で、apt 由来のパッケージが別途必要だった
FIX
設定画面の geometry/minsize 矛盾を解消
第2版では geometry("1080x640") と minsize(1200, 700) の値が逆転していた。画面サイズに応じて動的計算するロジックに変更。
FIX
フォント置換時の自己参照バグ（一時混入）
フォント変数化の過程で生じた FONT_UI = FONT_UI の自己参照を、案C採用時にクリーンアップ。フォールバック時に NameError 発生の可能性があった
FIX
スクロールバーが極細表示になる問題（Wayland）
tk.Scrollbar の width パラメータが Wayland で無視されていた。ttk.Style + clam テーマで 28px に明示指定。
